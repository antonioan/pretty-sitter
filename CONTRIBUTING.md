# Contributing to pretty-sitter

Thank you for your interest in contributing to pretty-sitter! We welcome contributions from the community and are excited to see what you'll bring to the project.

## Quick Start

1. **Read our documentation**: Start with the [development setup guide](docs/contributing/development-setup.md)
2. **Check existing issues**: Look for [good first issues](https://github.com/antonioan/pretty-sitter/labels/good%20first%20issue)
3. **Join the discussion**: Participate in [GitHub discussions](https://github.com/antonioan/pretty-sitter/discussions)

## Ways to Contribute

- **Report bugs** and request features through [GitHub issues](https://github.com/antonioan/pretty-sitter/issues)
- **Improve documentation** by fixing typos, adding examples, or clarifying explanations
- **Submit code changes** through pull requests
- **Help other users** by answering questions in discussions
- **Share your use cases** and provide feedback on the API

## Getting Started

### Development Environment

Follow our [development setup guide](docs/contributing/development-setup.md) to set up your local environment.

### Code Standards

Please read our [coding standards](docs/contributing/coding-standards.md) to understand our style guidelines and best practices.

### Architecture

Familiarize yourself with the [system architecture](docs/contributing/architecture.md) to understand how the components work together.

## Pull Request Process

Detailed pull request guidelines can be found in our [pull request guide](docs/contributing/pull-request-guidelines.md).

### Quick Checklist

Before submitting a pull request:

- [ ] Code follows our style guidelines
- [ ] Tests pass locally
- [ ] New functionality includes tests
- [ ] Documentation is updated if needed
- [ ] Commit messages are clear and descriptive

## Code of Conduct

We are committed to providing a welcoming and inclusive environment for all contributors. Please be respectful and professional in all interactions.

## Questions?

- Check our [FAQ](docs/troubleshooting/faq.md)
- Search [existing issues](https://github.com/antonioan/pretty-sitter/issues)
- Start a [discussion](https://github.com/antonioan/pretty-sitter/discussions)
- Contact the maintainers

We appreciate your contributions! 🎉
