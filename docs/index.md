# Pretty Sitter Documentation

Welcome to the Pretty Sitter documentation! Pretty Sitter is a Python library that provides pretty printing functionality for tree-sitter parse trees, allowing developers to visualize and analyze code structure in a formatted, colorized manner.

## Features

- 🎨 **Colorized Output** - Beautiful syntax highlighting for parse trees
- ⚙️ **Highly Configurable** - Extensive configuration options for customization
- 🔧 **Tree-Sitter Integration** - Works seamlessly with tree-sitter parsers
- 🐍 **Python 3.11+** - Modern Python support with type hints
- 📚 **Well Documented** - Comprehensive documentation and examples

## What is Tree-Sitter?

Tree-sitter is a parser generator tool and incremental parsing library that can build a concrete syntax tree for a source file and efficiently update the syntax tree as the source file is edited. Pretty Sitter helps you visualize these parse trees in a human-readable format.
