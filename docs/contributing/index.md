## Ways to Contribute

### Code Contributions

- **Bug fixes** - Help resolve issues reported by users
- **New features** - Implement requested functionality
- **Performance improvements** - Optimize existing code
- **Test coverage** - Add tests for untested code paths

### Documentation Contributions

- **Fix typos and errors** - Improve clarity and accuracy
- **Add examples** - Provide more usage examples
- **Improve guides** - Enhance existing documentation
- **Translate content** - Help make documentation accessible

### Community Contributions

- **Report bugs** - Help identify issues (see [Bug Reporting](../troubleshooting/bug-reporting.md))
- **Request features** - Suggest improvements
- **Help other users** - Answer questions in issues and discussions
- **Share use cases** - Show how you're using Pretty Sitter

## Development Workflow

1. **Fork the repository** on GitHub
2. **Set up your development environment** following the [Development Setup](development-setup.md) guide
3. **Create a feature branch** for your changes
4. **Make your changes** following our [Coding Standards](coding-standards.md)
5. **Add tests** for new functionality
6. **Run the test suite** to ensure everything works
7. **Submit a pull request** following our [Pull Request Guidelines](pull-request-guidelines.md)

## Code of Conduct

We are committed to providing a welcoming and inclusive environment for all contributors. Please be respectful and constructive in all interactions.

### Expected Behavior

- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Gracefully accept constructive criticism
- Focus on what is best for the community
- Show empathy towards other community members

## Recognition

Contributors are recognized in several ways:

- **Commit attribution** - Your contributions are tracked in git history
- **Release notes** - Significant contributions are mentioned in release notes
- **Contributors list** - Active contributors may be listed in project documentation

## Questions?

If you have questions about contributing that aren't covered in this documentation:

1. Check the [FAQ](../troubleshooting/faq.md) for common questions
2. Search existing [GitHub issues](https://github.com/antonioan/pretty-sitter/issues)
3. Create a new issue with the "question" label

We appreciate your interest in making Pretty Sitter better!
