# Getting Started

Welcome to Pretty Sitter! This section will help you get up and running quickly with the library.

## Quick Navigation

- **[Installation](installation.md)** - Install Pretty Sitter and its dependencies

## What You'll Learn

In this section, you'll learn how to:

1. Install Pretty Sitter in different Python environments
2. Set up tree-sitter parsers for your target languages
3. Create your first pretty-printed parse tree
4. Configure basic display options
5. Integrate Pretty Sitter into your workflow

## Prerequisites

Before getting started, make sure you have:

- Python 3.11 or higher
- Basic familiarity with Python programming
- Understanding of what syntax trees are (helpful but not required)
